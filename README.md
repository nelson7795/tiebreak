# Tiebreak

Tiebreak is a mobile-friendly decision app where a creator compares Option A vs Option B and shares a public voting link with friends.

## Live MVP
- A/B decisions
- Photos and product links
- Supabase persistence
- Public share links
- Anonymous voting
- Persistent results
- Edited photos are baked before sharing so voters see the creator's exact crop and orientation

## Stack
Static HTML/CSS/JavaScript + Supabase + Vercel.
